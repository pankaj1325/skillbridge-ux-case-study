# SkillBridge UX Case Study

SkillBridge is a responsive job discovery and career development prototype for
fresh graduates. The project includes a UX case study prototype built with
React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Run the prototype

The application is in the [`skillbridge/`](./skillbridge/) directory.

```bash
cd skillbridge
npm install
npm run dev
```

To create a production build:

```bash
cd skillbridge
npm run build
```

## Prototype scope

Search, filters, sorting, saved jobs, application status updates, skill
matching, learning roadmap progress, validation, and keyboard accessibility
are implemented in the browser. Jobs, companies, salaries, and learning steps
are fictional demo content. Sign-up and login are simulated, data is stored
locally in the browser, and there is no backend or resume upload.

See [`skillbridge/README.md`](./skillbridge/README.md) for more implementation
details and project structure.
